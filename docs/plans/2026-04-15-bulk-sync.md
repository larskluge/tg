# Bulk Sync Command Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `tg sync` command that fetches messages for multiple chats in a single TDLib session, reading per-chat high-water marks from stdin JSON and outputting results keyed by chat ID.

**Architecture:** New `src/commands/sync.rs` command module + `SyncArgs` in `cli.rs` + wiring in `main.rs`. Composes existing `get_boundary_message_id` and `get_messages` from `TelegramClient` trait — no new trait methods needed. Uses `parse_since_date` from `messages.rs` (made `pub(crate)`).

**Tech Stack:** Rust, serde_json for stdin/stdout, chrono for reconcile-days computation, existing TelegramClient trait + MockClient for tests.

```rust
use std::collections::HashMap;

use serde::Serialize;

use crate::client::TelegramClient;
use crate::commands::messages::parse_since_date;
use crate::error::Result;
use crate::output::MessageInfo;

/// Per-chat sync outcome: either messages or an error description.
#[derive(Debug, Serialize)]
#[serde(untagged)]
pub enum SyncResult {
    Messages(Vec<MessageInfo>),
    Error { error: String },
}

/// Parse stdin JSON into a map of chat_id -> HWM timestamp string.
pub fn parse_hwm_input(input: &str) -> std::result::Result<HashMap<i64, String>, String> {
    let raw: HashMap<String, String> =
        serde_json::from_str(input).map_err(|e| format!("Invalid JSON: {e}"))?;
    let mut result = HashMap::new();
    for (key, value) in raw {
        let chat_id: i64 = key
            .parse()
            .map_err(|_| format!("Invalid chat ID: {key}"))?;
        result.insert(chat_id, value);
    }
    Ok(result)
}

/// Bulk-sync messages for multiple chats within a single TDLib session.
///
/// For each chat in `hwm_map`, fetches messages newer than the HWM timestamp.
/// If `reconcile_days` is set, all HWMs are overridden with `now - N days`.
pub async fn sync_chats<C: TelegramClient>(
    client: &C,
    hwm_map: HashMap<i64, String>,
    limit: i32,
    reconcile_days: Option<u32>,
) -> HashMap<i64, SyncResult> {
    let effective_hwm: HashMap<i64, String> = if let Some(days) = reconcile_days {
        let cutoff = chrono::Utc::now() - chrono::Duration::days(days as i64);
        let cutoff_str = cutoff.to_rfc3339();
        hwm_map
            .keys()
            .map(|&chat_id| (chat_id, cutoff_str.clone()))
            .collect()
    } else {
        hwm_map
    };

    let mut results = HashMap::new();

    for (chat_id, hwm_str) in &effective_hwm {
        let result = sync_single_chat(client, *chat_id, hwm_str, limit).await;
        results.insert(*chat_id, result);
    }

    results
}

async fn sync_single_chat<C: TelegramClient>(
    client: &C,
    chat_id: i64,
    hwm_str: &str,
    limit: i32,
) -> SyncResult {
    let timestamp = match parse_since_date(hwm_str) {
        Ok(ts) => ts,
        Err(e) => return SyncResult::Error { error: e.to_string() },
    };

    // Warmup fetch to sync TDLib's local cache
    if let Err(e) = client.get_messages(chat_id, 1, None).await {
        return SyncResult::Error { error: e.to_string() };
    }

    // Find boundary message
    let boundary = match client.get_boundary_message_id(chat_id, timestamp).await {
        Ok(b) => b,
        Err(e) => return SyncResult::Error { error: e.to_string() },
    };

    use crate::client::BoundaryResult;
    let until_message_id = match boundary {
        BoundaryResult::Empty => return SyncResult::Messages(vec![]),
        BoundaryResult::BoundAt(id) => Some(id),
        BoundaryResult::None => {
            // Retry once after brief delay (stale index)
            tokio::time::sleep(tokio::time::Duration::from_millis(300)).await;
            match client.get_boundary_message_id(chat_id, timestamp).await {
                Ok(BoundaryResult::BoundAt(id)) => Some(id),
                Ok(BoundaryResult::Empty) => return SyncResult::Messages(vec![]),
                Ok(BoundaryResult::None) => None,
                Err(e) => return SyncResult::Error { error: e.to_string() },
            }
        }
    };

    match client.get_messages(chat_id, limit, until_message_id).await {
        Ok(mut messages) => {
            // If boundary lookup failed, filter by timestamp
            if until_message_id.is_none() {
                messages.retain(|m| m.timestamp >= timestamp);
            }
            SyncResult::Messages(messages)
        }
        Err(e) => SyncResult::Error { error: e.to_string() },
    }
}
```

```rust
Command::Sync(args) => {
    client.start().await?;
    client.wait_for_sync().await;

    let input = {
        use std::io::Read;
        let mut buf = String::new();
        std::io::stdin()
            .read_to_string(&mut buf)
            .map_err(|e| TgError::Other(format!("Failed to read stdin: {e}")))?;
        buf
    };

    let hwm_map = sync::parse_hwm_input(&input).map_err(|e| TgError::Other(e))?;
    let results = sync::sync_chats(client, hwm_map, args.limit, args.reconcile_days).await;

    let has_errors = results.values().any(|r| matches!(r, sync::SyncResult::Error { .. }));

    // Always output JSON (machine-only command)
    println!("{}", serde_json::to_string_pretty(&results).unwrap());

    if has_errors {
        return Err(TgError::Other("One or more chats failed to sync".to_string()));
    }
}
```

**Note:** The spec mentions exit code 2 for fatal stdin errors vs exit code 1 for partial failures. The existing `main.rs` uses a single `ExitCode::FAILURE` (1) for all errors. We keep that simplicity — consumers can distinguish fatal vs partial by checking whether stdout contains valid JSON output.
